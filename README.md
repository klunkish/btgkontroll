# BTG Quality Control 2.0.29

## Nytt i 2.0.29

Miljö-sidan har byggts ut med en mer korrekt EN 15804-struktur.

## Miljö-sidan innehåller nu

### Statusnivåer
- Utkast
- Internt underlag
- Granskningsunderlag
- Tredjepartsgranskat

### Standard och metod
- EN 15804+A2
- ISO 14025 / Typ III EPD
- PCR / c-PCR
- deklarerad enhet

### Livscykelmoduler
- A1 råvaror
- A2 transport till fabrik
- A3 tillverkning
- C1-C4 slutskede
- D nytta utanför systemgräns

### Klimatvärden
- GWP total
- GWP fossil
- GWP biogen
- GWP LULUC

### EPD och verifiering
- programoperatör
- EPD-/miljövarudeklarationsreferens
- publiceringsdatum
- giltig till
- verifieringsmetod
- granskare
- företag / organisation
- täckningsgrad
- tredjepartsgranskad / registrerad eller motsvarande

## PDF

**Miljö- och klimatunderlag för recept**
